# PixelUp 🚀

**AI-Powered Photo Enhancement Website**

PixelUp is a modern, mobile-friendly photo enhancement web application designed to improve image quality using AI-powered upscaling, denoising, and detail recovery.

## ✨ Features

- 🖼️ Upload images easily
- 🤖 AI-powered image enhancement
- 🔍 Image upscaling and detail recovery
- 🧹 Noise reduction and denoising
- 🎨 iPhone-inspired color grading
- ↔️ Before-and-after image comparison
- 📥 Download enhanced images
- 📱 Responsive, mobile-friendly interface

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **AI/Image Processing:** PyTorch and image-processing libraries

## 🚀 Getting Started

### Prerequisites
- Python 3.10–3.12 (64-bit)
- Git
- Internet connection for initial setup and model downloads

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/pixelup.git
   ```

2. Open the project folder:

   ```bash
   cd pixelup
   ```

3. Run the setup script on Windows:

   ```powershell
   .\setup.bat
   ```

4. Start the application:

   ```powershell
   .\run.bat
   ```

5. Open your browser at:

   `http://127.0.0.1:8000`
